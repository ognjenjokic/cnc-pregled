Sada:

Online pregled (QR kod u PDF-u)

Sa adresom svaka daska u PDF-u dobije QR kod: telefon otvori 3D sklopa sa tom daskom obojenom, stablo elemenata i podatke. „🌐 Objavi” pošalje projekat na sajt (kod.json i kod.glb u projekti/), a „Snimi projekat” ih snimi i lokalno. Sajt je javan: ko ima link, vidi projekat.

Kako postaviti GitHub Pages (jednom)
  1. Na github.com/new napravi repozitorij: ime npr. cnc-pregled, Public, uključi „Add a README file”.
  2. Token: novi fine-grained token – Repository access: Only select repositories → cnc-pregled; Permissions: Contents: Read and write i Pages: Read and write. Kopiraj token i zalijepi ga gore (čuva se samo u ovom pregledniku, ne ide u projekat).
  3. U terminalu npm run sajt, pa ovdje „⬆ Postavi sajt” i izaberi folder sajt.
  4. Za par minuta proba: adresa sajta + ?p=primjer. Poslije toga za svaki projekat samo „🌐 Objavi”.
